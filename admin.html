🎞️ वीडियो सूची / वीडियो हटाएँ

यहाँ सक्रिय वीडियो दिखेंगे। Delete करने पर वीडियो निष्क्रिय होगा, उससे जुड़े पुराने Access Codes बंद होंगे और Storage फ़ाइल हटाने की कोशिश होगी।

🔑 नया Access Code बनाएँ

खाली छोड़ने पर सिस्टम अपने आप कोड बनाएगा। अपना कोड 3–32 अक्षरों का रखें; अंग्रेज़ी अक्षर, अंक और हाइफ़न इस्तेमाल करें। कोड बनाते समय अक्षर बड़े किए जाएँगे।

समय आपके कंप्यूटर के स्थानीय समय के अनुसार चुना जाएगा। खाली छोड़ने पर कोड की समय-सीमा नहीं होगी।

✅ नया Access Code

इस कोड को अभी कॉपी करके सुरक्षित रख लें। पूरा कोड बाद में दोबारा नहीं दिखाया जाएगा।

📋 Access Code की सूची

यहाँ Access Code, संबंधित वीडियो, स्थिति और समय दिखाया जाएगा।
